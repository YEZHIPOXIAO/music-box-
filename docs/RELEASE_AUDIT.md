# 开源发布审计 — 2026-11-15

## 发布范围

这是从本地MusicBox1.0.6工作区生成的独立白名单源码导出，目录名MusicBox。没有复制旧运行文件夹或Git历史，没有自动初始化仓库、commit、推送或公开账号数据。

源目录没有.git，无法对不存在的历史声称“已重写/清除全部提交”。若维护者另有旧远端，需单独审计历史和附件。

## 隐私检查

- 收录Python/WinUI源码、合成tests、C#契约检查、源码构建/发布扫描脚本、许可原文和公共文档。
- 不收录账号数据库、密钥、WebView profile、Cookies、日志、真实扫码截图、头像、音频、歌词缓存、HAR、原生dump、抓取的官网JS、参考wheel或已登录测试版。
- 3个明确已知的原本机账号存储在内存中只读比较：密钥、账号密文、解密后的长凭据值及已知数字账号标识对最终95个公开源码文件均0命中。没有记录值、token片段、账号ID或密钥摘要。该结果只覆盖已知存储，不声称扫描了整台电脑。
- 发布扫描覆盖私钥格式、常见GitHub/云token、JWT、带授权参数音频URL、Windows/Unix个人路径及敏感文件类型；不会回显匹配值。
- 扫描器自测曾发现双反斜杠个人路径漏检，修正规则后重跑通过。规则扫描不是所有秘密格式的保证。
- 验证生成的bin/obj包含本机绝对路径，最终发布前物理删除；不只靠.gitignore隐藏。
- 原本机账号/密钥没有删除或撤销：它们留在原用户目录供本机继续使用，不进入公开导出。若要销毁本机凭据或历史远端泄漏需另行明确操作。

## 许可证与功能差异

1. MusicBox原有代码保留MIT License，持有人为MusicBox contributors，没有虚构作者真实姓名。
2. QQ扫码适配引用MIT包@yakult-green-tea/qq-music-api3.3.6，原许可及上游贡献署名已附。
3. L-1124/QQMusicApi发布版GPLv3+仅作为独立备用项目链接，没有复制/导入其代码或打包wheel。
4. 酷狗/酷我官网具体签名算法的可再分发许可未证实，**公开导出已移除对应函数体和算法fixture**，以显式本机适配接口替代。不能把公开版描述成会员播放适配开箱可用；本机完整版本未修改。
5. 无平台音频、封面、歌词、商标图片或官网脚本作为仓库资源。
6. 依赖license/version记录见DEPENDENCIES.json与THIRD_PARTY_NOTICES；源码MIT不覆盖第三方分发权或平台服务许可。本审计不是法律保证。
