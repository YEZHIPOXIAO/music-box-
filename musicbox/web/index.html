账号绑定

账号 Cookie 只会加密保存在本机（AES + HMAC），不会上传到任何服务器； 未登录也能播放各平台的免费曲目。

怎么复制 Cookie？
  1. 用浏览器打开对应音乐网站并登录。
  2. 按 F12 打开开发者工具 → Network（网络）标签。
  3. 刷新页面，点开任意一个请求，在 Headers → Request Headers 里找到 Cookie。
  4. 复制整行的值（形如 a=1; b=2; …），粘贴到上面的输入框。

提示：Cookie 等同于登录凭证，请勿分享给他人。本应用只在本机内存与本地加密库中使用它。
